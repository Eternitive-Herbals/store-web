# Aethery Store - Developer Documentation

Welcome to the internal developer documentation for the Aethery Store. This documentation serves as a comprehensive guide to understanding the architecture, features, and codebase structure of the e-commerce platform.

## Architecture Overview

Aethery is built using the **Next.js 16 (App Router)** framework. The application functions as a full-stack monolith, meaning both the frontend React components and the backend serverless API routes live within the same repository.

- **Frontend**: Built with React 19 and Tailwind CSS v4. State is managed via native React Context (`AuthContext`, `CartContext`).
- **Backend**: Implemented through Next.js Route Handlers (`app/api/*`). The application connects directly to a MongoDB database using Mongoose.
- **Authentication**: Custom implementation using JWTs (signed via `jose` for edge compatibility) stored in secure HTTP-only cookies. Passwords are hashed using `bcryptjs`.
- **Media Storage**: Product and blog images are uploaded directly from the client to AWS S3 using short-lived pre-signed URLs generated by the backend API.
- **Payments**: Integrated with the Razorpay API for processing customer transactions.

## Directory Structure

```text
d:\Projects\store-web\
├── app/                  # Core application directory (App Router)
│   ├── (auth)/           # Route group for authentication (login, register)
│   ├── (main)/           # Route group for public storefront (home, product, cart)
│   ├── account/          # Protected user account dashboard
│   ├── admin/            # Protected admin dashboard for inventory management
│   └── api/              # Backend serverless REST API endpoints
├── components/           # Reusable React UI components
│   ├── DataTable/        # Reusable table components for admin dashboards
│   ├── genericModal/     # Reusable modal logic and image uploaders
│   └── ...               # Modals, Headers, ProductCards, etc.
├── context/              # Global state providers
│   ├── AuthContext.tsx   # Manages user session state
│   └── CartContext.tsx   # Manages shopping cart state
├── hooks/                # Custom React hooks
├── lib/                  # Utility functions and server actions
│   ├── s3.ts             # AWS S3 client initialization
│   ├── uploadImage.ts    # Helper for handling client-side S3 uploads
│   └── ...Action.ts      # Various backend helpers/actions
├── models/               # MongoDB schema definitions (Mongoose)
└── types/                # TypeScript interfaces and type definitions
```
